# SmartVocab 📚

แอปเรียนคำศัพท์ภาษาอังกฤษแบบ Micro-Learning พร้อม Spaced Repetition

---


## ⚙️ Features

- **Weighted Spaced Repetition** — คำที่กด "ยังไม่รู้" จะโผล่บ่อยขึ้น 5×
- **Category Filter** — แท็บหมวดหมู่สร้างอัตโนมัติจาก vocab.json
- **Text-to-Speech** — ออกเสียงคำศัพท์ด้วย Web Speech API
- **Push Notification** — แจ้งเตือนทุก 3 ชั่วโมง
- **localStorage** — จำ progress ข้ามเซสชัน
